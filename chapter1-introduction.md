# Chapter 1 - Introduction to Networking

## What is Networking?

Networking is the process of connecting two or more devices so they can communicate and share resources such as files, printers, applications, and internet access.

---

# 1. LAN (Local Area Network)

A LAN is a network that covers a small geographical area such as a home, school, office, or college campus.

### Characteristics

* High speed
* Low latency
* Privately managed
* Covers a small area

### Example

A home Wi-Fi network connecting laptops, smartphones, and printers.

### Diagram

![LAN Diagram](images/lan-diagram.png)

---

# 2. MAN (Metropolitan Area Network)

A MAN connects multiple LANs across a city or metropolitan region.

### Characteristics

* Larger than LAN
* Covers a city or town
* Usually operated by ISPs or large organizations

### Example

Connecting multiple college campuses across Mumbai.

### Diagram

![MAN Diagram](images/man-diagram.png)

---

# 3. WAN (Wide Area Network)

A WAN connects networks across countries or continents.

### Characteristics

* Very large coverage area
* Uses routers and leased communication links
* Connects multiple LANs and MANs

### Example

A company with offices in India, USA, and UK.

### Diagram

![WAN Diagram](images/wan-diagram.png)

---

# 4. Internet

The Internet is the world's largest public network that connects billions of devices globally.

### Characteristics

* Publicly accessible
* Global connectivity
* Uses TCP/IP protocol suite

### Example

Browsing websites such as Google, YouTube, or GitHub.

### Diagram

![Internet Diagram](images/internet-diagram.png)

---

# 5. Intranet

An Intranet is a private network accessible only to authorized members of an organization.

### Characteristics

* Private and secure
* Internal communication
* Restricted access

### Example

Employee portals used by HR departments.

### Diagram

![Intranet Diagram](images/intranet-diagram.png)

---

# 6. Client-Server Network

In a Client-Server model, clients request services and servers provide them.

### Characteristics

* Centralized management
* Better security
* Easier backups

### Example

A web browser requesting a webpage from a web server.

### Diagram

![Client Server Diagram](images/client-server-diagram.png)

---

# 7. Peer-to-Peer (P2P)

In a Peer-to-Peer network, devices communicate directly without a dedicated server.

### Characteristics

* No central server
* Easy to set up
* Suitable for small networks

### Example

Sharing files directly between two computers.

### Diagram

![Peer to Peer Diagram](images/peer-to-peer-diagram.png)

---

# Summary

| Network Type | Coverage                       |
| ------------ | ------------------------------ |
| LAN          | Small Area                     |
| MAN          | City Level                     |
| WAN          | Country/Global                 |
| Internet     | Worldwide Public Network       |
| Intranet     | Private Organizational Network |

## Key Takeaways

* LAN is used for small areas.
* MAN connects multiple LANs across a city.
* WAN connects networks over long distances.
* The Internet is a public global network.
* An Intranet is a private internal network.
* Client-Server uses centralized resources.
* Peer-to-Peer allows direct communication between devices.
